R Shiny to extract feature from PubChem. 
This shiny app aims to help chemist to extract features of interest from PubChem which do not provide API. 

This app uses webscrapping to extract features which are then compiled in a easy-to-handle dataframe. 

The code is publicly available on GitHub : [https://github.com/remylegoff/Chem_Quest](https://github.com/remylegoff/Chem_Quest)
The app is available [here](https://remylegoff-chem-quest.share.connect.posit.cloud/)
