R Shiny pour l'extraction d'informations à partir de PubChem

Cette application utilise le webscrapping pour extraire les informations depuis PubChems qui ne fournit pas d'API précise. 
Les informations sont extraites par webscrapping et compilées dans un dataframe utilisable facilement. 

Le code est disponible sur GitHub : [https://github.com/remylegoff/Chem_Quest](https://github.com/remylegoff/Chem_Quest)
L'application est aussi disponible gratuitement ici : [here](https://remylegoff-chem-quest.share.connect.posit.cloud/)
